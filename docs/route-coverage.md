# Route registration coverage

`python3 tests/route_coverage.py` compares the pinned Fizzy revision's
dispatchable Rails routes with the Rust router. The inventory is generated by
`tests/source_route_inventory.rb` using each controller's `action_methods`, so
Rails-generated routes without a callable action do not inflate the count.
Path parameters and account mount prefixes are normalized before comparison.

| Route source | Registered in Rizzy | Missing |
| --- | ---: | ---: |
| Fizzy application controllers | 211 | 0 |
| Turbo Native navigation | 3 | 0 |
| Active Storage | 9 | 0 |
| Action Mailbox | 14 | 0 |

The three Turbo Native history endpoints now return the pinned source's 200
HTML responses and exact text, with and without the account prefix. All nine
Active Storage routes are now registered. The blob proxy streams the
original bytes and supports single byte ranges; `tests/storage_proxy_parity.py`
compares private/public access and cache headers against live Fizzy and Rizzy
instances. `tests/storage_representation_parity.py` compares generated image
representation redirects, proxies, aliases, access, tampered variation keys,
cache headers, and file cleanup. Rizzy signs its own variation keys and supports
the app's limit/fill resize operations. It does not yet decode Rails-signed
variation keys, implement arbitrary transformations, reproduce libvips bytes,
or preview non-image files. Rizzy now prepares the 800×600 and 1024×768 image
variants when an image is embedded in rich text; the paired representation
test confirms both cache files exist before the first image request.

The 14 Action Mailbox routes are installed by Rails, but Fizzy has no mailbox
classes or configured ingress. `tests/action_mailbox_parity.py` runs disposable
production Fizzy and Rizzy servers and compares all 14 method/path responses,
three `.json` suffixes, HTML and JSON Accept headers, and anonymous and
bearer-token requests. Both return empty HTML 404 responses for six inactive
ingress methods and empty HTML 403 responses for four conductor reads. Four
conductor writes without CSRF tokens return the same 422 JSON or static HTML
body according to the requested format. Development conductor behavior and
configured ingress behavior remain unimplemented in Rizzy; these routes are
outside the production app's normal workflow.

This check establishes path and HTTP-method registration only. It does not
verify response shape, permissions, side effects, browser behavior, or whether
an unregistered Rails framework route is used by Fizzy. `--strict` exits
nonzero while any registered source route remains unmatched.
