# Route registration coverage

`python3 tests/route_coverage.py` compares the pinned Fizzy revision's
dispatchable Rails routes with the Rust router. The inventory is generated by
`tests/source_route_inventory.rb` using each controller's `action_methods`, so
Rails-generated routes without a callable action do not inflate the count.
Path parameters and account mount prefixes are normalized before comparison.

| Route source | Registered in Rizzy | Missing |
| --- | ---: | ---: |
| Fizzy application controllers | 211 | 0 |
| Turbo Native navigation | 3 | 0 |
| Active Storage | 4 | 5 |
| Action Mailbox | 0 | 14 |

The three Turbo Native history endpoints now return the pinned source's 200
HTML responses and exact text, with and without the account prefix. The five
unregistered Active Storage routes include blob proxy and legacy alias paths
plus general representation routes. The 14 Action Mailbox routes are installed
by Rails in the source; their actual availability and behavior outside the
test environment still need comparison.

This check establishes path and HTTP-method registration only. It does not
verify response shape, permissions, side effects, browser behavior, or whether
an unregistered Rails framework route is used by Fizzy. `--strict` exits
nonzero while any registered source route remains unmatched.
